TS 2. Total Station Observation
Local X,Y: +y = away from the rig (opposite the Bow, i.e. the direction the instrument faces), +x = right-hand side when facing that direction (the rig's Port side). This matches how a total station is normally set up at the stern.
Gon (also called "grad"): a metric angle unit where a full circle = 400 gon (so 100 gon = 90°, 200 gon = 180°). Used on some total stations, mostly older European/Asian models. If you're not sure, your instrument almost certainly reads in Degree — leave this on Degree unless you know for certain your instrument outputs gon.
If the total station is not set up exactly at Center Stern (0,0) — e.g. it's set up at dx=-10, dy=-5 relative to it, because that point isn't physically accessible — enter that offset here, using the same +y/+x convention as above. Every sighting below (in either mode) is measured from the instrument and automatically combined with this offset. Leave at 0,0 if the instrument is set up exactly at Center Stern. Once a fit is available (≥2 points bound), a diamond marker labelled "TS Instrument" appears on the plot at the computed real-world location of your instrument setup, connected to the Stern marker by a dashed line — use it to visually confirm the offset was entered correctly (does the marker sit roughly where you actually stood, relative to the rig?).
Need at least 2 points that are both filled in and bound on the drawing before a fit can be computed
3. Rig Profile / Skid Envelope
Skid X/Y are entered as plain positive magnitudes (feet). The envelope is always placed on the side opposite the Bow automatically — you never need to type a negative number.
The Skid Envelope is drawn automatically — as soon as Total Station (2), Plan (4), and/or Navigation (5) has a valid position, its envelope appears in that source's colour. No extra step needed.
Only used to decide which envelope Slot accessibility is tested against — does not affect what is drawn on the plot.

SLOT 6. Slot Accessibility Check optional
Reads POINT / CIRCLE centers and closed LWPOLYLINE centroids on the selected layer. A nearby TEXT label (within 5 m) is used as the slot name if found. Existing slots are kept — points within 0.05 m of an existing slot are skipped as duplicates.
Checked against the Skid Envelope of the reference source selected in section 3.
